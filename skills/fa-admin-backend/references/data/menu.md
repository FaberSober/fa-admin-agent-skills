# 菜单段位表

菜单 ID 是 8 位数字，按 `aa.bb.cc.dd` 四段分配：`aa`=顶部业务模块，`bb`=二级模块，`cc`=菜单，`dd`=功能点。

框架内置模块占用段位：

| 段位 | 模块 | 说明 |
| --- | --- | --- |
| `1x.00.00.00` | fa-base | 框架基础模块 |
| `20.00.00.00` | fa-demo | 框架演示模块 |
| `21.00.00.00` | fa-app | APP 模块 |
| `22.00.00.00` | fa-disk | 网盘模块 |
| `26.00.00.00` | fa-tenant | 多租户模块 |

新业务模块另选未占用 `aa` 段，挂载前在目标库 `SELECT id FROM base_rbac_menu` 查重。

菜单 SQL 写法和字段顺序见 [ddl.md](ddl.md)。
